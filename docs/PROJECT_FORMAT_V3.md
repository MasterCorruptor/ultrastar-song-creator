# Project format v3

Status: reviewed v3 implementation in the approved combined package. Owner authorized publication/main integration2026-10-14; current PR/Git history records integration. Sourcebd8addb and combined773/773 evidence are recorded in [integration report](LYRICS_COMBINED_LOCAL_REVIEW.md).

Frozen profile for the bounded selected-lyrics package. Extends [v2](PROJECT_FORMAT_V2.md) and preserves the frozen v1/v2 song and imported-source payloads.

The UTF-8 JSON root has exactly `format`, `schemaVersion`, `song`, `importedSource`, `selectedLyrics`. `format` is `ultrastar-song-creator`, writer version is 3. `importedSource` and `selectedLyrics` are required nullable properties. The shared legacy `song` payload is unchanged. Readers dispatch explicitly on 1, 2, 3, report the original version, and never rewrite on load. V1 migrates both fields to null; v2 preserves imported source and migrates selected lyrics to null. Explicit save writes v3.

`selectedLyrics` is null for no choice, or an object with exactly required `kind`, nullable `document`, and nonnull `provenance`. Kind is `text` or `instrumental`; text requires exactly one document, instrumental requires document null. No inference from empty text, notes or source headers.

Document required properties: `id`, `text`, `syncLevel`, `lines`, `timeReference`. Sync is `plain`, `line`, `word`; time reference is `lyricsSourceSeconds`. Lines have required `text`, `startSeconds`, nullable `endSeconds`, `words`. Words have required `text`, `startSeconds`, nullable `endSeconds`. Text is exact Unicode/LF, including spaces, repeated lines and trailing lines. No normalization, clipping, raw LRC or guessed offset.

Provenance required properties: `origin`, `sourceId`, `candidateId`, nullable `sourceUrl`, nullable `createdAtUtc`, nullable `retrievedAtUtc`, nullable `artist`, `title`, `album`, `version`, nullable `durationSeconds`. Origin is `manual` or `provider`. Manual uses source `manual`, a canonical lowercase nonempty GUID-D candidate ID, URL null, nondefault UTC creation and retrieval null. Provider uses a source other than `manual`, opaque bounded candidate ID, optional canonical HTTPS URL, creation null and nondefault UTC retrieval. Claims are inert data; load/save perform no fetch. Times retain existing snapshots; none are generated.

Unknown, duplicate, missing, incorrectly cased, null-required, wrong-type and undefined enum values are rejected. JSON schema failures are InvalidJson, envelope/version failures retain InvalidEnvelope/UnsupportedVersion. Structural domain failures are InvalidSong with typed InvalidSelectedLyrics issues at selectedLyrics. Logical size excess is TooLarge during read preflight, InvalidSong during save validation. Preflight checks counts and logical strict UTF-8 budgets before selected DTO arrays: document 64 + id/text bytes + each line 48/text bytes + each word 32/text bytes, max 256 KiB; whole selection adds provenance string bytes and 128, max 512 KiB. At most 10000 lines and 50000 total words. ID limit 256 UTF-16, metadata/URL 4096. Source times are finite 0–14400, null ends allowed, ordered starts, words within line bounds; simultaneous starts and overlap allowed. Global 64 MiB and depth 64 remain. Atomic save/cancellation/failure preservation remain unchanged.

DTOs and frozen enum names are independent of Acquisition/provider records. Only selected document/provenance persist. No unselected variants, cache, query, capabilities, diagnostics, media lookup, analysis or automatic downgrade. `SetSelectedLyrics` validates before change, explicit null clears, equality covers every field including dates and IDs, equal independently allocated arrays preserve redo. Undo/redo restore immutable recorded snapshots. Existing song/source/media/offsets/metadata/notes/analysis retain authority.
