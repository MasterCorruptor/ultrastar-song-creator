## One recommended next block: G1 local PCM preprocessing + worker boundary
Input: current immutable Song snapshot plus explicit normalized MediaCandidate/selected audio-stream index and current SelectedLyrics. Output: an immutable, independently reviewed PreprocessingProposal containing a private normalized PCM WAV descriptor, bounded waveform bins and job/media/lyrics provenance. It must never execute an edit or generate/replace Song, notes, metadata, BPM, selected lyrics or offsets.

Use .NET10 to supervise two sequential child processes: existing compatible minimal FFmpeg decodes only the chosen local audio stream to mono16kHz PCM16 WAV; then isolated Python3.12 stdlib worker reads that WAV in chunks and returns deterministic peak waveform bins. No model, NumPy, ASR, resynthesis or hand-written resampler is needed. The decode format is this stage's analysis representation, not a global playback/separation default; retain original media for later stereo/rate needs. This is a usable preprocessing/analysis artefact, not a generated song or pitch/alignment result.

Out of scope: GUI/app wiring, persistent cache/application command/schema migration, vocal separation/umxhq integration, pitch, BPM, ASR/alignment/notes/confidence scoring, automatic downloads/installers/default ASR, new models, GPU, release packaging. Keep one job at a time; no parallel worker graph before this boundary is accepted.

## Proposed frozen contract — review before implementation
- .NET PreprocessingRequest captures OriginalSong by immutable reference, SourceMediaId resolving once in Song.Media, MediaCandidate, explicit audio stream, SelectedLyrics and a new JobId. Generation may reference Core+Acquisition only for these existing normalized records; Acquisition must not depend on Generation. Validate with existing selected-lyrics rules; explicit instrumental is valid and causes no invented text.
- Copy chosen regular source into job-owned staging while SHA256 is computed; input cap1GiB. Validate bytes/selection against the supplied candidate and current content; if a downloaded hash is supplied, require equality. Detect concurrent change and fail SourceChanged; operate on the frozen copy. Source labels are provenance (downloaded media may retain a local-file candidate); match actual location/content/stream rather than requiring source-label equality. No header/ID/filename heuristics for stream or metadata. Source filesystem access is not a security sandbox.
- Times are **DecodedPcmSeconds**, with frameCount and16kHz giving exact frame-index conversion. Zero is first emitted sample. MediaInspection has no stream start-PTS; preserve OriginInMediaSeconds=null unless independently proven. Never equate this clock with Song seconds or LyricsSourceSeconds, or apply AudioOffset/VideoOffset. Original lyrics timestamps are unchanged; no alignment occurs.
- Parent request preserves exact SelectedLyrics and identity/hash; G1 worker needs only an opaque selection digest, not raw text. Python request/result protocol has version1+JobId+stage, fixed relative PCM leaf, shape/hash/producer revision and waveform bins. Full Song/provider responses/tags/lyrics body never go through stdout/logs. No timestamps/IDs are regenerated to make results look current.
- Strict one request.json/one final stdout JSON object, closed stdin, UTF8, depth16, unique/known properties, finite numbers, matching version/job/stage. Request<=64KiB, stdout<=1MiB, stderr<=64KiB, waveform<=4096 bins; each bin uses start/end frame and min/max, no fabricated confidence. Reject extra responses, missing/unknown fields, NaN, mismatched sample count/hash, trailing data and invalid paths. These are proposed v1 limits, not existing guarantees.
- New staging only; fixed relative filenames, no overwrite/URL/arbitrary worker paths. Validate containment and reject reparse/symlink escapes/unexpected files; destination and inputs never share identity. Decoded cap30min/64MiB; exceeding duration is an error, never an accepted silent trim. Any codec cap must allow detecting one sample beyond the accepted duration. Monitor growth and validate final WAV/header/frame/byte count: best-effort file limits are not OS disk/RAM/CPU quotas.
- Supervisor .NET runner uses absolute configured executables, ArgumentList/no shell/PATH lookup, fixed job CWD, simultaneous bounded stdout/stderr reads, Python -I/-X utf8, no inherited model/cache/network configuration. FFmpeg file-only format/codec whitelist and -map for the selected index; no nested Python-spawned codec process. Whole-job deadline includes source copy/hash/decode/worker/validation (proposed default120s, max10min).
- Cancellation/deadline/output/pipe/process failure kills owned process tree as needed and awaits exit plus all readers before cleanup/next job. Reuse the proven process-boundary principles; Acquisition.ProbeProcess is internal/domain-specific and closes stdin, so do not make it public or opportunistically refactor it. Stage-specific fixed error codes (source/selection/unavailable/decode/worker/invalidresponse/limits/timeout); caller cancellation stays OCE after drain, never raw stderr in UI/public errors.
- On success validate all artefacts, write minimal manifest and publish only the complete new job directory; later cancellation cannot turn an already published result into deletion. Return relative assets + hashes/byte counts/frame shape/runtime/script/codec identity. Delete only owned validated staging on failure. No project history or existing user file is rewritten; no crash/fsync guarantee.
- Core.AnalysisKind may identify Waveform; Core.AnalysisArtifact/Point cannot alone convey this clock/hash/stream/run provenance. Use a new transient Generation envelope/bin record; do not attach it to Song.Analysis or change Projects/schema. Caller must compare OriginalSong reference/current source identity before any future explicit acceptance; Song.Id alone cannot detect edits. Stale proposals may be inspected, never auto-applied.
